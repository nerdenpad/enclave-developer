Private AI meets programmable USDC payments.

How per-call settlement and mandates fit into the sealed agent lifecycle.

/IN THIS ARTICLEMeter each requestBound the agentDisclose with purposeExplore without moving funds

Meter each request

Per-call accounting links model usage to payment. The Enclave specification targets USDC with x402 or Nanopayments, allowing wallet-enabled agents to pay for inference inside explicit mandates.

Bound the agent

A spending mandate defines limits before execution. Prefunded and collateralized lanes describe different funding arrangements. A breached mandate rejects the call.

Disclose with purpose

Confidential transfers shield amounts while addresses remain visible. Scoped auditor view keys and receipt exports are intended to support selective review without disclosing private inference content.

Explore without moving funds

The workspace simulates accounting and mandate checks. Its displayed amounts are illustrative values, not published fees, balances or live settlements.
