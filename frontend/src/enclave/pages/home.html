/FAQ

Frequently
Asked
Questions

What does Enclave keep private?+

The intended execution path keeps prompts, model memory and outputs inside an attested CPU and GPU environment. Requests are encrypted, TLS terminates in the confidential virtual machine, and operational records contain hashes rather than plaintext inputs or outputs.

What does an inference receipt prove?+

A receipt records the model hash, code hash, input and output hashes, attestation reference, timestamp and signature. It provides provenance for an approved execution environment. It does not prove that the model’s answer is correct.

How are inference calls paid for?+

The protocol is designed for per-call USDC settlement through x402 or Nanopayments. Arc confidential transfers shield amounts; addresses remain visible. Agent mandates set spending limits.

What are sealed agents?+

Sealed agents keep their model, memory and policy inside the enclave. The planned runtime connects these agents to a wallet, spending mandates and signed receipts for their actions.

Is this dashboard connected to live infrastructure?+

This site connects to a hosted development backend. Wallet sign-in is available. The configured NEAR integration requires successful hardware verification before inference; a configured provider does not mean a request has completed. Settlement uses MockUSDC on local Anvil, not Arc. Public paid inference and production hardware key custody are not enabled. See deployment status for the current settings.
